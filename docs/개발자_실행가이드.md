# 개발자 실행 가이드

Java 17, Node 22.12 이상 권장. Docker 없이 자동 테스트와 프론트 빌드를 실행할 수 있습니다.

## 자동 검사

```powershell
cd backend
.\gradlew.bat test bootJar --no-daemon --console=plain
cd ../compass-frontend
npm ci
npm run lint
npm run build
```

Linux/macOS는 ./gradlew를 사용합니다. 일반 테스트는 H2와 외부 API mock을 사용하며 Google 자격증명·운영 DB·크레딧이 필요하지 않습니다. 실제 PostgreSQL/Google 통합 검증을 대신하지 않습니다. LivePlanGenerationTest는 RUN_LIVE_AI_TEST=true일 때만 실행됩니다.

## 로컬 서버

PostgreSQL이 필요합니다. 별도 개발 DB를 쓰거나, Docker가 설치되어 있다면 기존 Compose의 postgres 서비스만 실행할 수 있습니다.

```powershell
docker compose up -d postgres
```

기존 Compose는 pgvector 이미지를 유지하지만 새 앱은 벡터 확장을 쓰지 않습니다. Redis도 필요 없습니다. 기존 데이터 볼륨을 삭제하거나 이미지를 무턱대고 바꾸지 않습니다.

IDE 실행 환경변수 또는 backend/.env에서 설정합니다. spring-dotenv가 실행 디렉터리의 .env를 읽으므로 루트 .env가 항상 자동 적용된다고 가정하지 않습니다.

```dotenv
DB_HOST=localhost
DB_PORT=5433
DB_NAME=compass
DB_USERNAME=compass_user
DB_PASSWORD=<개발 DB 비밀번호>
GOOGLE_CLIENT_ID=<OAuth ID>
GOOGLE_CLIENT_SECRET=<OAuth Secret>
JWT_SECRET=<긴 무작위 값>
GOOGLE_PROJECT_ID=<Google Cloud 프로젝트>
GOOGLE_CLOUD_LOCATION=global
GOOGLE_CREDENTIALS_URI=file:C:/YOUR_PROJECT/secrets/gcp-sa.json
GOOGLE_PLACES_API_KEY=<서버 전용 개발 키>
CORS_ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
OAUTH2_REDIRECT_URI=http://localhost:5173/oauth2/redirect
```

로컬 기본 쿠키는 Secure=false, render 프로필에서는 true입니다. 로컬에 render 프로필을 적용하지 않습니다. Google OAuth 승인 콜백은 http://localhost:8080/login/oauth2/code/google입니다. server Places 키의 IP 제한과 브라우저 키의 referrer 제한을 구분합니다.

```powershell
cd backend
.\gradlew.bat bootRun
```

compass-frontend/.env:

```dotenv
VITE_API_BASE_URL=http://localhost:8080
VITE_GOOGLE_MAPS_API_KEY=<브라우저 개발 키>
```

```powershell
cd compass-frontend
npm run dev
```

Vite의 /api/auth 개발 프록시가 쿠키 인증을 localhost:8080으로 연결합니다. 프론트 포트를 바꾸면 CORS/OAuth 완료 주소와 키 제한도 맞춥니다. Vite preview에는 dev proxy를 가정하지 않습니다.

## 실제 Google 생성 테스트 (사용량 발생)

backend에서 RUN_LIVE_AI_TEST=true, GOOGLE_PROJECT_ID, GOOGLE_PLACES_API_KEY를 JVM에 전달합니다. ../secrets/gcp-sa.json 파일이 필요합니다. 테스트는 앱 DB 없이 1일 여행을 생성합니다.

```powershell
$env:RUN_LIVE_AI_TEST='true'
.\gradlew.bat test --tests '*LivePlanGenerationTest' --no-daemon --console=plain
Remove-Item Env:RUN_LIVE_AI_TEST
```

인증/키 원문을 테스트 출력·문서·커밋에 넣지 않습니다. 현재 확인한 로컬 키는 IP 제한으로 차단돼 있으므로 개발 키 설정 후 실행해야 합니다.
