# 개발자 실행 가이드

이 문서는 **처음 프로젝트를 내려받은 개발자**가 로컬에서 바로 실행할 수 있도록 정리한 가이드입니다.

## 0. 사전 준비
- Git
- Docker Desktop
- Java 17
- Node.js 20+

권장 확인:
```bash
java -version
node -v
docker -v
```

## 1. 저장소 클론
```bash
git clone https://github.com/KHSBE/KHSBE-AIT.git
cd KHS-BE
```

## 2. 환경 변수 설정

### 2-1. 백엔드 (`backend/.env` 또는 OS 환경변수)
아래 키를 준비하세요.

```env
DB_HOST=127.0.0.1
DB_PORT=5433
DB_NAME=compass
DB_USERNAME=compass_user
DB_PASSWORD=compass_password

REDIS_HOST=localhost
REDIS_PORT=6379

GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GOOGLE_AI_STUDIO_API_KEY=your_gemini_api_key
WEATHER_API_KEY=your_weather_api_key
JWT_SECRET=your_jwt_secret

CORS_ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
OAUTH2_REDIRECT_URI=http://localhost:5173/oauth2/redirect
```

### 2-2. 프론트 (`compass-frontend/.env`)
```env
VITE_API_BASE_URL=http://localhost:8080
VITE_GOOGLE_MAPS_API_KEY=your_google_maps_api_key
```

## 3. 로컬 인프라 실행
프로젝트 루트에서 실행:
```bash
docker compose up -d
```

확인:
```bash
docker compose ps
```
- `compass-db` / `compass-redis`가 `Up`이면 정상

## 4. 백엔드 실행

macOS/Linux:
```bash
cd backend
./gradlew bootRun
```

Windows:
```powershell
cd backend
.\gradlew.bat bootRun
```

기본 포트: `8080`

## 5. 프론트 실행
```bash
cd compass-frontend
npm install
npm run dev
```

기본 포트: `5173`

브라우저 접속:
- `http://localhost:5173`

## 6. Google OAuth 설정 체크
Google Cloud Console OAuth 클라이언트에 아래를 등록해야 로그인 오류(`redirect_uri_mismatch`)를 피할 수 있습니다.

- 승인된 JavaScript 원본
  - `http://localhost:5173`
- 승인된 리디렉션 URI
  - `http://localhost:8080/login/oauth2/code/google`

## 7. 자주 발생하는 문제

### 7-1. DB 연결 실패 (`role does not exist`)
- 로컬 DB 계정/비밀번호가 `.env`와 맞는지 확인
- `docker compose down -v` 후 `docker compose up -d`로 초기화

### 7-2. CORS 에러
- `CORS_ALLOWED_ORIGINS`에 `http://localhost:5173` 포함 확인
- 백엔드 재시작

### 7-3. OAuth `redirect_uri_mismatch`
- Google Console의 Redirect URI와 실제 백엔드 콜백 URI가 완전히 일치하는지 확인

### 7-4. 포트 충돌
- 5433/6379/8080/5173을 다른 프로세스가 쓰는지 확인

## 8. 종료 방법

프론트/백엔드 터미널: `Ctrl + C`

인프라 종료:
```bash
docker compose down
```

데이터까지 초기화:
```bash
docker compose down -v
```
