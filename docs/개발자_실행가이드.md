# 개발자 실행 가이드

배포 서버를 이용해 개발한다면 로컬 서버와 Docker는 필수가 아닙니다.
로컬에서는 단위 테스트와 프론트 빌드만 실행할 수 있습니다.
클라우드 설정은 [배포 가이드](RENDER_DEPLOYMENT.md)를 따릅니다.

## 도구와 테스트

Java 17, 프로젝트 잠금파일에 맞는 Node/npm을 준비합니다.
현재 Vite가 요구하는 Node 버전은 package-lock.json 및 패키지 engines를 확인합니다.

```powershell
cd backend
.\gradlew.bat test --no-daemon --console=plain
cd ../compass-frontend
npm ci
npm run lint
npm run build
```

Linux/macOS에서는 gradlew.bat 대신 ./gradlew를 사용합니다.
현재 테스트는 주로 단위 테스트이며 실제 DB/Google 연동 검증을 대신하지 않습니다.

## 로컬 전체 실행 (선택)

PostgreSQL을 직접 설치하거나 루트에서 개발용 Compose를 실행합니다.

```powershell
docker compose up -d postgres redis
```

현재 Compose의 호스트 DB 포트는 **5433**입니다. 컨테이너 내부 포트 5432와 구분합니다.
Redis는 Compose에 있지만 현재 애플리케이션에서 직접 사용하는 코드는 없습니다.
개발 DB는 공개 서비스 DB와 분리합니다.

## 백엔드 설정

실행 환경변수를 IDE에서 지정하거나 backend/.env에 준비합니다.
루트 .env가 어떤 작업 디렉터리에서도 자동 적용된다고 가정하지 않습니다.
아래 비밀 값 예시는 실제 값으로 대체하고 커밋하지 않습니다.

```dotenv
DB_HOST=localhost
DB_PORT=5433
DB_NAME=compass
DB_USERNAME=compass_user
DB_PASSWORD=compass_password
GOOGLE_CLIENT_ID=<OAuth ID>
GOOGLE_CLIENT_SECRET=<OAuth secret>
JWT_SECRET=<충분히 긴 무작위 비밀값>
GOOGLE_PROJECT_ID=<Google Cloud 프로젝트>
GOOGLE_GENAI_VERTEX_AI=true
GOOGLE_CLOUD_LOCATION=global
GOOGLE_CREDENTIALS_URI=file:C:/YOUR_PROJECT/secrets/gcp-sa.json
GOOGLE_APPLICATION_CREDENTIALS=C:/YOUR_PROJECT/secrets/gcp-sa.json
GOOGLE_PLACES_API_KEY=<서버 Places 키>
WEATHER_API_KEY=<날씨 키>
CORS_ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
OAUTH2_REDIRECT_URI=http://localhost:5173/oauth2/redirect
```

서비스 계정 파일을 실제 로컬 절대 경로로 지정합니다.
특히 ADC 환경변수는 JVM 프로세스가 읽을 수 있도록 IDE 실행 환경에 지정합니다.
로컬에서 Render 전용 프로필을 활성화하면 DB_JDBC_URL 등이 필요하므로 프로필을 혼용하지 않습니다.
모델/쿼터/Places 세부 옵션은 코드 기본값을 사용하거나 [배포 가이드](RENDER_DEPLOYMENT.md)의 기본값 표를 참고합니다.
PLACES_VERIFICATION_MIN_SCORE는 정수 점수이며 소수 확률을 넣으면 안 됩니다.

Google OAuth 승인 콜백:

```text
http://localhost:8080/login/oauth2/code/google
```

Google Cloud에서 AI 및 Places API 사용 권한을 확인합니다. 지도/경로 기능에는 해당 브라우저 API도 필요합니다.
브라우저 키의 사이트 제한과 서버 키의 제한은 용도가 다릅니다. 보안을 위해 모든 제한을 해제하지 않습니다.

```powershell
cd backend
.\gradlew.bat bootRun
```

## 프론트 설정과 실행

compass-frontend/.env:

```dotenv
VITE_API_BASE_URL=http://localhost:8080
VITE_GOOGLE_MAPS_API_KEY=<브라우저 지도 키>
```

```powershell
cd compass-frontend
npm ci
npm run dev
```

터미널에 표시된 주소로 접속합니다. 포트가 5173이 아닌 경우 CORS와 프론트 완료 주소도 맞춥니다.
환경변수 변경 후 개발 서버를 재시작합니다.
로컬 실행도 실제 AI/Places API를 호출하면 사용량이 발생합니다.

## 오류 확인

인증 파일, CORS, OAuth, Places 오류는 [운영 런북](서버_운영_런북.md)을 참고하되
클라우드 주소 대신 해당 로컬 주소를 사용합니다. 429는 앱 쿼터인지 공급자 제한인지 먼저 구분합니다.
