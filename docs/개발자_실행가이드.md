# 개발자 실행 가이드

Compass를 로컬에서 실행하고 검증하기 위한 문서입니다.

## 사전 준비

- Java 17
- Node.js 20 이상
- Docker Desktop
- PostgreSQL 15 이상 또는 Docker Compose
- Redis 7 이상 또는 Docker Compose
- Google Cloud 프로젝트
- Google OAuth 클라이언트
- Google Maps/Places API 키
- Vertex AI 서비스 계정 JSON

## 필요한 Google API

Google Cloud Console에서 아래 API를 활성화합니다.

- Vertex AI API
- Places API(New)
- Maps JavaScript API
- Routes API

OAuth 승인된 리디렉션 URI는 로컬 기준으로 아래 값을 추가합니다.

```text
http://localhost:8080/login/oauth2/code/google
```

프론트엔드 최종 리디렉션은 백엔드 환경변수 `OAUTH2_REDIRECT_URI`로 제어합니다.

```text
http://localhost:5173/oauth2/redirect
```

## 1. 의존 서비스 실행

로컬 PostgreSQL/Redis가 없다면 Docker Compose로 띄웁니다.

```bash
docker compose up -d postgres redis
```

프로젝트의 `docker-compose.yml`에 서비스명이 다르면 해당 파일 기준으로 실행합니다.

## 2. Vertex AI 서비스 계정 준비

Google Cloud에서 서비스 계정 키 JSON을 내려받아 프로젝트 루트의 `secrets/gcp-sa.json`에 둡니다.

```text
C:\Users\momki\Desktop\KHS-BE\secrets\gcp-sa.json
```

`secrets/`는 `.gitignore` 대상이어야 합니다. 절대 GitHub에 올리지 않습니다.

## 3. 백엔드 환경변수

`backend/.env` 또는 IDE 실행 환경에 아래 값을 설정합니다.

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=compass
DB_USERNAME=compass_user
DB_PASSWORD=compass_password

REDIS_HOST=localhost
REDIS_PORT=6379

CORS_ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
OAUTH2_REDIRECT_URI=http://localhost:5173/oauth2/redirect

GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...

GOOGLE_GENAI_VERTEX_AI=true
GOOGLE_PROJECT_ID=...
GOOGLE_CLOUD_LOCATION=global
GOOGLE_CREDENTIALS_URI=file:../secrets/gcp-sa.json
AI_MODEL_GENERAL=gemini-3.1-flash-lite-preview
AI_MODEL_PLAN=gemini-3.1-pro-preview
AI_MODEL_PLAN_FALLBACK=gemini-3.1-flash-lite-preview

GOOGLE_PLACES_API_KEY=...
GOOGLE_PLACES_LANGUAGE=ko
PLACES_VERIFICATION_ENABLED=true
PLACES_VERIFICATION_MAX_PLACES=30
PLACES_VERIFICATION_MIN_SCORE=0.55
PLACES_VERIFICATION_CANDIDATES_PER_QUERY=3
PLACES_VERIFICATION_CACHE_TTL_HOURS=24

WEATHER_API_KEY=...
JWT_SECRET=...
ADMIN_EMAILS=admin@example.com

PLAN_QUOTA_PER_DAY=3
CHAT_QUOTA_PER_DAY=10
```

Windows에서 상대 경로가 맞지 않으면 `GOOGLE_CREDENTIALS_URI`를 절대 경로로 바꿉니다.

```env
GOOGLE_CREDENTIALS_URI=file:C:/Users/momki/Desktop/KHS-BE/secrets/gcp-sa.json
```

## 4. 백엔드 실행

```bash
cd backend
./gradlew bootRun
```

Windows PowerShell에서는 아래처럼 실행할 수 있습니다.

```powershell
cd backend
.\gradlew.bat bootRun
```

## 5. 프론트엔드 환경변수

`compass-frontend/.env`를 생성합니다.

```env
VITE_API_BASE_URL=http://localhost:8080
VITE_GOOGLE_MAPS_API_KEY=...
```

## 6. 프론트엔드 실행

```bash
cd compass-frontend
npm install
npm run dev
```

브라우저에서 접속합니다.

```text
http://localhost:5173
```

## 7. 검증 명령

백엔드 테스트:

```bash
cd backend
./gradlew test
```

프론트엔드 lint/build:

```bash
cd compass-frontend
npm run lint
npm run build
```

## 자주 나는 오류

### Google 로그인 후 `redirect_uri_mismatch`

Google Cloud OAuth 클라이언트에 백엔드 콜백 URI가 등록되어 있는지 확인합니다.

```text
http://localhost:8080/login/oauth2/code/google
https://api.compass-travel.site/login/oauth2/code/google
```

### `Failed to get application default credentials`

Vertex AI 인증 파일 경로가 잘못된 상태입니다. `GOOGLE_CREDENTIALS_URI`와 실제 `gcp-sa.json` 위치를 확인합니다.

### Places 검증이 동작하지 않음

아래 항목을 확인합니다.

- Places API(New) 활성화 여부
- API 키 제한 도메인/리퍼러 설정
- `GOOGLE_PLACES_API_KEY` 값
- `PLACES_VERIFICATION_ENABLED=true`

### CORS 오류

프론트엔드 origin이 `CORS_ALLOWED_ORIGINS`에 포함되어야 합니다.

```env
CORS_ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

### 쿼터 초과 429

사용자별 일일 일정 생성/채팅 제한을 초과한 상태입니다. 로컬에서는 관리자 페이지 또는 DB에서 쿼터를 초기화합니다.
