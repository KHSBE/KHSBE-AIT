# 🧭 Compass: AI 기반 개인화 여행 에이전트 통합 마스터 가이드

## 1. 프로젝트 개요 및 핵심 가치

**서비스명**: Compass (AI 기반 개인화 여행 에이전트)

**핵심 컨셉**
사용자의 **암묵적 선호도를 벡터화하여 저장**하고, **실시간 외부 정보(날씨, 관광 API)** 와 결합하여 최적의 여행 경험을 제공하는 **컨텍스트 인지형 AI 에이전트**.

**개발 목표**

* 1인 개발로 백엔드와 프론트엔드 완수
* 정보처리기사 합격
* 실무급 포트폴리오 확보

## 3. 상세 데이터베이스 설계 (ERD)

> 1인 개발 생산성을 극대화하기 위해 **JSONB 필드**를 적극 활용한 설계

### 주요 테이블

* **users**
  사용자 정보 및 여행 성향(preferences JSON) 저장

* **chat_threads**
  대화 세션 관리용 UUID 기반 스레드

* **messages**
  USER / ASSISTANT 대화 내역 및 메타데이터 저장

* **trips**
  AI가 생성한 여행 마스터 데이터

* **trip_details**
  일자별 장소, 시간, 메모 등 상세 일정

* **travel_embeddings**
  pgvector 기반 장소 정보 및 사용자 선호도 벡터 데이터

## 5. GitHub Actions CI/CD 설정 (ci.yml)

> 코드 푸시 시 자동 빌드 및 보안 설정 복원

경로: `.github/workflows/ci.yml`

```yaml
name: Compass CI

on:
  push:
    branches: [ "main", "develop" ]
  pull_request:
    branches: [ "main", "develop" ]

jobs:
  build:
    runs-on: ubuntu-latest
    env:
      GOOGLE_CLOUD_PROJECT_ID: ${{ secrets.GOOGLE_CLOUD_PROJECT_ID }}
      GOOGLE_CREDENTIALS_BASE64: ${{ secrets.GOOGLE_CREDENTIALS_BASE64 }}

    steps:
    - uses: actions/checkout@v3

    - name: Set up JDK 17
      uses: actions/setup-java@v3
      with:
        java-version: '17'
        distribution: 'temurin'

    - name: Setup Google Cloud Credentials
      run: |
        echo "$GOOGLE_CREDENTIALS_BASE64" | base64 -d > ./gcp-key.json
        echo "GOOGLE_APPLICATION_CREDENTIALS=$(pwd)/gcp-key.json" >> $GITHUB_ENV

    - name: Grant execute permission for gradlew
      run: chmod +x gradlew

    - name: Build with Gradle
      run: ./gradlew build -x test
```
