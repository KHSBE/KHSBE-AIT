# 서버 운영 런북

현재 구성: Vercel + Render + Neon. 최초 설치와 전체 환경변수는
[배포 가이드](RENDER_DEPLOYMENT.md)를 기준으로 합니다. EC2 기록은 [보관 문서](archive/EC2_운영_런북.md)에 있습니다.

## 상태 확인

1. Render Deploys에서 최신 배포 Live, 커밋, Logs의 첫 오류를 확인합니다.
2. Vercel Deployments에서 Ready뿐 아니라 Production Current인지 확인합니다.
3. 프론트에서 로그인, 채팅, 일정 생성, 저장/조회까지 각각 확인합니다.

```powershell
curl.exe -I --max-time 90 https://khsbe-ait.onrender.com/oauth2/authorization/google
```

Google 인증 URL로 302 응답하면 로그인 시작 경로는 동작합니다. 로그인 완료·DB·AI 정상까지 증명하지 않습니다.
응답의 state, 세션 쿠키, 토큰을 공유하지 않습니다. 로그인 없는 /api/plans의 401은 정상일 수 있습니다.
API 루트는 사용자용 홈페이지가 아닙니다.

## 이번 이전에서 발생한 문제

| 증상 | 확인 / 대응 |
| --- | --- |
| Your default credentials were not found | Secret File과 GOOGLE_APPLICATION_CREDENTIALS=/etc/secrets/gcp-sa.json 확인. file: 없음 |
| 로그인 버튼이 옛 AWS로 이동 | Vercel Production의 VITE_API_BASE_URL 확인 후 프론트 재빌드. Render 재배포만으로 해결 안 됨 |
| redirect_uri_mismatch | 실제 요청의 redirect_uri와 Google OAuth 승인 주소 비교 |
| 로그인 후 localhost / 잘못된 사이트 이동 | Render OAUTH2_REDIRECT_URI 확인 |
| CORS 차단 | 실제 브라우저 origin과 CORS_ALLOWED_ORIGINS 비교. 인증을 무작정 해제하지 않음 |
| 첫 접속이 오래 걸림 | 무료 서버 휴면 가능. 기동 로그 확인 후 재시도 |
| Places 검증이 생략됨 | 서버 키, API 활성화/제한, enabled 설정, search_error 로그 확인 |
| 429 | 우리 쿼터인지 공급자 제한인지 응답과 로그로 구분 |
| 500 / 502 | 예외 스택 맨 끝만 말고 첫 오류와 Caused by 확인 |
| OOM / 반복 재시작 | Metrics와 생성 중 메모리 확인. 힙만 늘리거나 유료 전환하지 말고 원인 분석 |
| column does not exist | 연결 DB/스키마와 현재 코드 확인. 백업 없이 컬럼 삭제나 임의 DDL 실행 금지 |

## 변경 반영과 복구

- 코드 변경: CI 결과를 확인한 뒤 해당 플랫폼 배포 상태와 커밋을 확인합니다.
- 환경변수: Render와 Vercel은 서로 별개이며 로컬 .env도 자동 전달되지 않습니다.
- 잘못된 프론트 배포: 이전 정상 배포로 되돌릴 수 있으나 그 배포에 포함된 API 주소도 확인해야 합니다.
- 잘못된 백엔드 배포: 이전 호환 커밋 재배포를 검토합니다. DB 스키마와 호환되는지 먼저 확인합니다.
- 환경변수 변경 기록에는 이름과 변경 이유만 남기고 실제 비밀 값은 기록하지 않습니다.
- DB 주소 변경은 데이터 이전이 아닙니다. 데이터가 필요하면 별도 백업·복원이 필요합니다.

## 데이터와 비용

Neon 콘솔의 SQL Editor로 테스트 데이터 존재 여부를 확인할 수 있습니다.
이메일·대화 내용 등 개인정보가 보이는 결과를 공개하지 않습니다.
중요 데이터는 PostgreSQL 백업 도구로 별도 보관하고 복원 테스트를 수행합니다.
현재 ddl-auto=update는 마이그레이션 이력/백업을 대체하지 않습니다.

Render 휴면은 DB 삭제가 아닙니다. Neon 프로젝트/브랜치를 삭제하는 작업과 구분합니다.
무료 한도, 외부 API 사용량, 크레딧 만료를 각각 확인합니다. 예산 알림은 지출 차단 장치가 아닙니다.
