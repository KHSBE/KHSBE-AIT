1. 프로젝트 정체성 및 목표프로젝트 명: Compass (나침반)핵심 컨셉: 사용자의 자연어 요청을 분석하여 개인 취향과 제약 사항(다이어트, 예산 등)을 반영한 최적의 여행 경로를 제안하는 지능형 여행 플래닝 에이전트.목표: 실무급 기술 스택(Java 21, Spring Boot 3.4, Querydsl, Redis, Spring AI)을 활용한 풀스택 포트폴리오 완성.2. 기술 스택 (Tech Stack)Backend: Java 21, Spring Boot 3.4, Spring Data JPA, Querydsl, Spring AI, Spring Security (JWT).Database: MySQL (메인), Redis (캐싱 및 세션).Frontend: React (Vite + TypeScript), Tailwind CSS, TanStack Query, Zustand.DevOps: Docker, GitHub Actions (CI/CD).3. 디렉토리 구조 (Architecture)실무형 도메인 주도 설계(DDD) 스타일을 적용하여 com.compass 패키지 하위에 다음과 같이 구성했습니다.global/: common(응답 규격), error(전역 예외 처리), config(Security, JPA 설정).domain/: user, plan, place, agent 도메인별로 api, application, domain(Entity), dao(Repository), dto 분리.infra/: ai(Spring AI 연동), maps(Google Maps API 연동) 등 외부 시스템 전용 레이어.4. 완료된 데이터 모델링 (Entity 구현)모든 엔티티는 **지연 로딩(LAZY)**과 **BaseEntity(시간 자동 기록)**를 적용하여 구현을 마쳤습니다.도메인클래스명핵심 역할공통BaseEntity모든 테이블의 생성/수정 시간 자동 관리회원User, UserPreference사용자 기본 정보 및 AI 추천의 근거가 될 취향 데이터 저장계획TravelPlan여행의 큰 틀 (제목, 지역, 기간)일정Itinerary일차별 그룹화 (1일차, 2일차 등)장소Place구체적인 방문 장소, 좌표, 방문 순서, AI의 추천 사유(Memo)에이전트ChatSession, ChatMessageAI와의 대화 맥락 유지 및 이력 관리5. 핵심 기술 포인트 (포트폴리오 어필용)데이터 무결성: @NoArgsConstructor(access = AccessLevel.PROTECTED)를 통해 객체의 무분별한 생성을 제한.성능 최적화: 모든 연관 관계에 LAZY 전략을 사용하여 N+1 문제 방지 기틀 마련.에이전트 특화: 단순 일정 저장이 아닌, 대화 세션(ChatSession)과 취향(Preference)을 연결하여 지능형 에이전트의 토대 구축.🚀 다음 단계 (Next Steps)다음에 작업을 재개할 때 아래 순서대로 진행하는 것을 추천합니다.Repository 레이어 구축: JpaRepository 생성 및 동적 검색을 위한 Querydsl 전용 Repository 설정.Spring AI 연동: infra/ai 패키지에서 OpenAI 또는 Gemini API를 호출하여 자연어를 JSON 일정 데이터로 변환하는 로직 구현.Security & JWT: 회원가입/로그인 기능 및 토큰 기반 인증 시스템 구축.Frontend 초기 연동: React에서 백엔드 API를 호출하여 에이전트 채팅창 UI 구성.오늘 고생 많으셨습니다! 밤 10시 운동(버피와 푸시업) 잊지 마시고, 푹 쉬었다가 다음 코딩 때 뵙겠습니다. 건승하세요!
