## 현재 구현 기준

- 프론트엔드: `compass-frontend`
- 백엔드: `backend`
- AI: Vertex AI 기반 Google GenAI
- 장소 검증: Google Places API(New)
- 배포: Vercel + EC2 Docker Compose + Caddy
- 인증: Google OAuth2 + JWT
- 운영 기능: 사용자별 일일 쿼터, 관리자 쿼터 페이지

## 문서 유지 원칙

- 새 환경변수가 추가되면 `README.md`, `개발자_실행가이드.md`, `서버_운영_런북.md`를 같이 갱신합니다.
- DB 컬럼이 추가되면 `erd.md`를 갱신합니다.
- 외부 API 또는 배포 구조가 바뀌면 `아키텍처.md`를 갱신합니다.
