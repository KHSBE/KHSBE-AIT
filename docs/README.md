## 정리 원칙

- 배포 환경변수와 설정 절차는 배포 가이드 한 곳에서 관리합니다.
- README에는 소개와 진입 링크만 두어 설정 중복을 줄입니다.
- 과거 운영 방식은 archive, 시안은 prototypes에 분리합니다.
- 설계와 실제 구현을 구분하고 미완료 기능을 완료라고 쓰지 않습니다.
- 비밀 값, 서비스 계정 JSON, 개인 사용자 정보는 문서에 넣지 않습니다.
- 코드 변경 시 관련 문서와 상대 링크도 점검합니다.
