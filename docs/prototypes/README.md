# 일정 상세 디자인 시안 01

- 파일: `itinerary-preview.html` (UTF-8, 단독 HTML)
- 기존 React 앱, 로그인, 운영 API, DB를 수정하거나 호출하지 않습니다.
- Google Fonts 로딩 외에 자동 외부 요청은 없습니다. 지도 확인 버튼은 사용자 클릭 시 Google Maps 장소명 검색을 엽니다.
- 여행/검증 상태/방문 시간은 모두 고정 예시입니다. 지도는 실제 지리 위치나 경로를 나타내지 않는 SVG 개념도입니다.

## 디자인 방향

Compass 블루를 유지하고 아이보리 배경, 짙은 본문, 여백 중심 타임라인으로 위계를 구분합니다. 정확도 퍼센트 대신 확인할 항목을 보여줍니다. 예시 상태가 실제 검증처럼 오해되지 않도록 전역 안내와 상세 출처를 명시했습니다.

## 확인할 흐름

1. 데스크톱: 날짜 전환 → 일정 카드 선택 → 지도 마커 강조 → 상세 보기.
2. 모바일(390px 또는 360px): 지도 보기 → Day 2 → 지도 모드 유지 → 마커 선택 → 상세 보기.
3. 확인하기 → 확인 필요 장소 → 해당 날짜와 선택 장소 변경.
4. 상세 패널: 자체 스크롤, 닫기, Escape, 키보드 Tab, 배경 스크롤 차단.
5. 일정/지도 전환 시 각 보기의 스크롤 위치 복원.
6. 장소 바꾸기는 다음 단계의 설명만 표시합니다. 후보 검색과 실제 교체/저장은 구현 범위가 아닙니다.
